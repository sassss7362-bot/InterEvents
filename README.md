# InterEvents 2.0

Світові події та унікальні PvP-предмети для Paper **1.16.5 – 26.x** (компілюється проти 1.16.5, Java 8 target).

## Збірка
Завантаж проєкт на GitHub — Actions збере jar (`Actions → Build InterEvents → Artifacts`).
Локально: `mvn package` → `target/InterEvents-1.0.0.jar`.

## Події (6)
| ID | Що відбувається |
|---|---|
| mysticchest | ✦ Містичний сундук: промінь із неба → спуск по спіралі → удар блискавки → зона зачекання (PvP за лут) → відкриття, бонус першому відкривачу |
| deathchest | ☠ Сундук смерті: блискавки й душі → виринає з-під землі → прокляття зони + 3 хвилі охоронців (Жнець у фіналі) → відкриття |
| meteor | ☄ Метеорит: червоне коло й промінь → вогняна куля з неба → вибух, кратер, руда метеорита; рейтинг за видобутком |
| airdrop | ✈ Небесний дар: сундук на парашуті, його треба захопити, утримуючи точку сам на сам |
| worldboss | Світовий бос: ритуал виклику, фази, блискавки, ударна хвиля, прислужники, затягування |
| chatgame | Швидкі завдання в чаті (захист від ботів) |

У сундуках — лут + **унікальні талісмани та сфери** (налаштовуються вагами в `unique-pool`).

## Унікальні предмети (`/event give <гравець|*> <id> [к-сть]`)
**Талісмани** (працюють у будь-якому слоті інвентаря):
`talisman_dragon` (+12% шкоди) · `talisman_phoenix` (рятує від смерті, 180 c) · `talisman_vampire` (лайфстіл 15%) · `talisman_titan` (-12% вхідної шкоди) · `talisman_griffin` (Швидкість I, без шкоди від падіння)

**Сфери** (в основній або лівій руці; ПКМ — здібність з перезарядкою):
`sphere_chaos` (дебафи) · `sphere_ice` (заморозка) · `sphere_fire` (вогняне кільце) · `sphere_life` (лікування) · `sphere_shadow` (ривок + невидимість)

Усі числа — у `config.yml → unique`.

## Налаштування
1. Станьте в центрі області й напишіть `/event setarena all` (або для окремої події `/event setarena <id>`). Події з'являються у випадковій точці в `radius` навколо центру. Без цього — навколо спавну світу.
2. `/event start <id>` або `auto.enabled: true`.

## Команди
`/event list | info | top | stats` · Адмін: `start <id>`, `stop`, `setarena <id|all>`, `tp`, `give`, `items`, `reload`, `auto on|off`, `ac <гравець>`
Права: `interevents.use`, `interevents.admin`, `interevents.bypass`, `interevents.alerts`

## Античіт (гравці в зоні події)
speed, fly/зависання, reach, CPS, nuker, gamemode, блок tp-команд, блок заборонених команд (`zone-blocked-commands`), політ вимикається в зоні, захист chat-game від ботів. Накопичує VL з затуханням; при max-vl — позбавлення участі + `punish-commands`.
